SHEIKH WEATHER — GitHub Pages Upload Guide (বাংলা)

এই ZIP-টি Extract করার পর ভেতরের ফাইল/ফোল্ডারগুলো সরাসরি GitHub Repository-এর Root-এ আপলোড করবেন।

সঠিক কাঠামো:
  index.html
  .nojekyll
  manifest.webmanifest
  service-worker.js
  assets/
    css/styles.css
    js/app.js
    icons/icon.svg

গুরুত্বপূর্ণ:
1. ZIP ফাইলটিকে GitHub-এ একক ফাইল হিসেবে আপলোড করবেন না।
2. Extract করা ফোল্ডারের ভেতরের সব ফাইল ও assets ফোল্ডার একসঙ্গে আপলোড করবেন।
3. Repository Root-এ index.html থাকতে হবে; index.html-এর ভেতরে আরেকটি parent folder রাখা যাবে না। ZIP-এর সব ফাইল/ফোল্ডার একসঙ্গে আপলোড করুন—CSS/JS ও PWA-এর জন্য assets ফোল্ডারও দরকার।
4. GitHub → Settings → Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
5. Upload শেষে Commit changes দিন এবং Pages deployment সম্পূর্ণ হওয়া পর্যন্ত অপেক্ষা করুন।
   লোগো আপডেট না দেখালে সাইটে Ctrl+F5 দিয়ে hard refresh করুন; GitHub Pages deploy হতে কয়েক মিনিট লাগতে পারে।
6. এই URL-এ পরীক্ষা করুন:
   https://ahmadsaad8420-stack.github.io/-SHEIKH-WEATHER-/
7. CSS সরাসরি পরীক্ষা:
   https://ahmadsaad8420-stack.github.io/-SHEIKH-WEATHER-/assets/css/styles.css

যদি CSS URL-এ 404 আসে, তাহলে assets/css/styles.css GitHub Repository-এর Root-এর নিচে
ঠিক ওই path-এ আপলোড হয়নি। এই ZIP-এ ফাইলটি আছে; সঠিকভাবে Extract করে সব contents আপলোড করতে হবে।

নোট: Live weather, geocoding, air quality ও radar-এর জন্য ইন্টারনেট প্রয়োজন।
